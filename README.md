# Sistema de Materiais de Comunicação

## Sobre a atividade

Este projeto foi desenvolvido como atividade da disciplina de **Desenvolvimento para Servidores I**.

O objetivo é aplicar conceitos de **Programação Orientada a Objetos** na criação de um sistema simples voltado para o gerenciamento de materiais de comunicação online e offline.

## Conceitos utilizados

Durante o desenvolvimento foram utilizados os conceitos trabalhados em aula:

- Classes e objetos
- Atributos e métodos
- Construtores
- Encapsulamento
- Getters e Setters
- Herança
- Sobrecarga de métodos
- Sobrescrita de métodos

## Tecnologias

- Java
- Visual Studio Code
- GitHub
